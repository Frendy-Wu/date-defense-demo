## 当前项目

- 名称：《约会保卫战》，浏览器塔防 demo。
- 技术：Phaser、TypeScript、Vite，Excel 配表使用 SheetJS。
- 9:16 竖屏、电脑鼠标操作；逻辑画布 540 × 960，设计单位 1080 × 1920。
- 当前 README 标记为第一阶段：部署、基础攻击、五波流程、胜败结算、暂停/倍速、Excel 导入导出及素材映射。
- 五种防御物开场可用，各一个实例，部署后跨波保留，不移动、不出售。
- 五种防御物当前使用基础攻击；Boss 当前按普通耐久结算；画面主要为程序占位图形。
- 正式设计和后续范围详见 `docs/方案规划.md`。

## 后续尚待实现的设计

- 五种塔的专属机制：吸取、燃烧、捕获/消化、拦截、藤蔓。
- 不同攻击导致的狗仔退场表现、情侣的分波姿态。
- Boss 分阶段演出和巨人两拳终结。
- 正式美术替换、动画与节奏打磨。

这些是原方案中的后续阶段；下一次开发先确认用户想推进哪部分。

## 文件入口

- `src/model.ts`：独立战斗状态与五波流程。
- `src/config.ts`：配置数据、Excel 校验/导入/导出。
- `src/scene.ts`：Phaser 渲染与鼠标交互。
- `src/main.ts`、`src/style.css`：页面 UI 和布局。
- `public/assets/`：美术素材；`public/data/约会保卫战配置.xlsx`：配置工作簿。
- `tests/`：模型与浏览器检查。

## 启动与检查

Node.js 版本要求见 README。首次运行 `npm ci`，之后 `npm run dev`；Windows 也可双击 `启动游戏.cmd`。

模型测试：`npm test`。构建检查：`npm run build`。浏览器测试需先启动开发服务器，详见 README。

本次交接整理只修改同步说明和忽略规则，没有修改游戏代码，也没有重新运行游戏测试。
