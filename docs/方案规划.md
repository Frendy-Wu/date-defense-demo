这版 demo 暂定名为 **《约会保卫战》**，核心体验是：玩家把美国街边的生活物品部署到道路两侧，物品经过夸张变身后阻挡狗仔，保护底部正在约会的情侣。共 5 波，最后以魔法豆茎巨人两拳击败 Boss 收尾。

**1. Demo 范围与画面布局**

采用 **9:16 竖屏画面，在电脑上通过鼠标操作**，建议按 1080 × 1920 设计，窗口内等比例缩放。

| 区域 | 内容 |
|---|---|
| 顶部 | 波次 UI、能量 UI、狗仔入场与行进路线 |
| 中部 | 连续的狗仔道路、道路两侧部署位、街景中的可选物品 |
| 底部 | 情侣约会区域、情侣头顶共用血条、人物表情与姿态反馈 |

顶部和中部路线相连，狗仔从上向下接近情侣。场景采用美国街边咖啡店外的环境，融入汽车、空调外机、雨棚、停车牌与藤蔓。

本次不接入照片上传或 AI 转化，不做塔升级、合成和复杂经济系统。先用占位素材完成玩法，后续替换你的美术资产。

**2. 部署与战斗规则**

五种物品开场全部解锁，准备阶段和出怪过程中都能部署，每波部署数量不限。

首版按**每种物品一个实例，共五座塔**设计，不提供重复建造。道路两侧先安排约 8 个合法部署位，供玩家选择位置。

操作流程：

1. 鼠标经过可部署物品，主体平滑放大约 8%，离开后恢复。
2. 点击物品，出现持续描边或光圈，显示可部署方格。
3. 鼠标经过有效方格，显示物品预览和作用范围。
4. 点击方格，扣除能量，物品移动到目标位置并播放变身动画。
5. 变身结束后自动攻击。玩家可以继续选择、部署其他物品。

点击空白处或按 Esc 取消选择。非法位置、已占用方格不允许部署，也不扣能量。

塔部署后持续留场；第五波被摧毁的塔变为残骸。首版部署后不提供出售与移动，避免扩大操作范围。

**3. 五种防御物设计**

| 物品 | 部署后外观 | 攻击方式 | 关键表现 |
|---|---|---|---|
| 空调外机 | 外机变形，吸水管明显突出 | 范围持续伤害，同时吸取多个狗仔 | 相机、外层衣物被吸走；狗仔血量归零后转身返回并渐隐 |
| 汽车 | 车灯变大、聚光结构突出 | 单体照射，附带燃烧效果 | 相机冒烟、身体出现卡通火焰；燃烧致败时直接渐隐 |
| 雨棚 | 变为春卷机 | 一次最多捕获两名非 Boss 狗仔，捕获后进入消化冷却 | 消化完沿道路反向抛出，狗仔翻滚后渐隐 |
| P 字停车牌 | 变为停车场拦车杆 | 阻挡普通狗仔，让其他塔集中输出 | 杆体伸入道路，狗仔在杆前聚集；本体仍位于路边 |
| 藤蔓 | 变为巨大绿色豆荚，内部隐约可见巨人轮廓 | 普通阶段用藤蔓抽击；Boss 最终阶段触发巨人终结 | 豆荚展开，巨人露出上半身，体型与肌肉明显超过 Boss，两拳终结 |

藤蔓的普通攻击作为提前部署时的基础用途，表现保持简单，突出第五波的巨人反转。

狗仔的退场方式由最终击败他的攻击决定。已经被春卷机捕获或正在退场的狗仔，不再被其他塔攻击，也不会伤害情侣。

**4. 五波战斗结构**

敌人数量全部使用 Excel 配置，不在程序中写死。各波不限制玩家使用哪座塔。

| 波次 | 敌人组成 | 体验重点 |
|---|---|---|
| 第一波 | 普通狗仔 × X | 认识路线、自由选择物品，体验部署与变身 |
| 第二波 | 普通狗仔 × X、长焦狗仔 × X | 敌人数量和耐久提高，体验多塔配合 |
| 第三波 | 普通、长焦、户外专业狗仔 × 各自 X | 更高压力，展示春卷机双目标捕获 |
| 第四波 | 大批量混合狗仔 | 展示拦车杆聚怪与范围攻击配合 |
| 第五波 | 大体型 Boss 狗仔 × 1 | 逐个突破防御，魔法豆茎完成反转 |

普通狗仔耐久较低；长焦狗仔耐久更高、突破后的伤害更高；户外专业狗仔耐久最高。首版都沿固定路线移动，不额外加入远程射击 AI。

每波结束条件为：本波敌人全部生成，且场上已无仍在进攻的敌人。留出短暂清场反馈后，玩家点击“下一波”继续，也可以先部署剩余物品。

**5. Boss 分阶段演出**

第五波采用阶段控制，保证故事顺序清楚，同时兼容玩家自由部署。

| 阶段 | 行为 |
|---|---|
| 空调试探 | 若空调已部署，吸取 Boss，只造成少量伤害 |
| 车灯激怒 | 若汽车已部署，照射使 Boss 爆衣，进入爆发状态，伤害仍然很低 |
| 怒吼破坏 | 若雨棚已部署，尝试捕获 Boss，随即被怒吼摧毁 |
| 拳断栏杆 | 若停车牌已部署，Boss 被短暂拦住后，一拳打断栏杆 |
| 最终对峙 | 引导玩家部署藤蔓；若已部署，则直接激活豆荚 |
| 巨人终结 | 巨人出现，第一拳重创 Boss，第二拳击败 Boss |

未部署的物品跳过对应演出，不自动替玩家建塔。Boss 阶段允许继续部署，每个演出节点检查对应塔是否已经就绪；已经跳过的节点不回放。

最终对峙阶段，Boss 在情侣前方短暂停留，等待藤蔓部署完成，给玩家理解提示和操作的时间。巨人登场后锁定终结演出，避免其他攻击提前结束战斗。

Boss 普通受击采用高减伤，最终两拳采用固定剧情结算，确保数值调整不会破坏结局。

**6. 情侣反馈、血条与 UI**

情侣头顶共用一根血条。普通狗仔到达终点后播放偷拍动作，扣除共同血量并离场；血量为零则失败。

每波采用不同的慌张与放松姿态：

| 波次 | 来袭时的慌张 | 清场后的放松 |
|---|---|---|
| 第一波 | 惊讶回头、身体靠近 | 松口气、相视一笑 |
| 第二波 | 女方挡脸、男友侧身遮挡 | 放下手、整理衣服 |
| 第三波 | 缩肩躲避、紧拉手臂 | 舒展身体、轻拍胸口 |
| 第四波 | 相互搂紧、紧张张望 | 放松倚靠、擦汗 |
| 第五波 | 后退、抱紧对方 | 欢呼拥抱、恢复甜蜜 |

姿态优先级为：**胜败结算 → 被偷拍时的短暂惊吓 → 当前波次姿态**，避免动画互相覆盖。

必要 UI 包括：

- **波次**：显示“第 1 / 5 波”，配合来袭和清场提示。
- **能量**：显示当前数值，成功部署时显示扣除动画。
- **共同血条**：固定跟随情侣，扣血时明显反馈。
- **操作提示**：简短提示“选择街边物品”“选择部署位置”。
- **结算**：胜利或失败，以及“重新开始”。

初始能量按配表保证足够部署全部五种物品，暂不设计恢复、击杀奖励和资源经营。

**7. Excel 配表**

使用一个 `.xlsx` 工作簿，提供开发调试用导入入口。导入后先校验，再通过重新开局应用配置。

| 工作表 | 配置内容 |
|---|---|
| 全局 | 情侣最大血量、初始能量、波间反馈时长 |
| 狗仔 | 类型、血量、移动速度、突破伤害 |
| 防御物 | 部署能量、攻击力、攻击间隔、射程、目标数量 |
| 特殊效果 | 燃烧伤害与时长、春卷机容量与消化时间、拦车杆阻挡上限 |
| 波次 | 波次、敌人类型、数量、出场延迟、生成间隔 |
| Boss | 血量、速度、减伤比例、阶段演出时长 |
| 资源映射 | 物品及敌人 ID、对应素材路径、显示尺寸与锚点 |

攻击频率统一用“攻击间隔，单位秒”填写。校验至少覆盖五波完整性、类型引用、负数和缺失字段；错误时指出具体工作表与行号，避免游戏运行到一半才失败。

**8. 实现方式与美术准备**

建议使用 **Phaser + TypeScript + Vite** 制作浏览器版本，方便在电脑上打开和演示。战斗逻辑、Excel 配置、角色动画与 Boss 演出分别管理，后续更换美术不需要改战斗规则。

美术资源按以下类别准备：

| 类别 | 所需状态 |
|---|---|
| 场景 | 无交互物品的背景、道路、前景遮挡层 |
| 五种生活物品 | 原始外观、变身过程、工作状态、攻击表现 |
| 雨棚与停车牌 | 额外准备损坏状态 |
| 三类普通狗仔 | 行走、受击、返回、燃烧、翻滚；可拆分相机与外层衣物 |
| Boss | 行走、轻微受击、爆衣、怒吼、挥拳、被巨人击中、退场 |
| 魔法豆茎 | 豆荚、巨人轮廓、展开、巨人上半身、两次出拳 |
| 情侣 | 五组慌张、五组放松、被偷拍反馈、胜败姿态 |
| 特效 | 吸力、光束、烟雾、火焰、捕获、冲击、渐隐 |

可交互物品需要与背景分开，角色身体、相机和可被吸走的衣物尽量分层，方便实现变形与装备脱落。

**9. 开发顺序与验收**

分三个阶段交付：

1. **可玩框架**：竖屏场景、鼠标交互、部署位、能量扣除、道路移动、共同血条、五波流程和 Excel 导入。
2. **完整机制**：五种塔的攻击、狗仔退场状态、情侣姿态切换、Boss 阶段与巨人终结。
3. **演示打磨**：替换美术、调整变身和攻击反馈、优化节奏，完成整局试玩。

验收重点是：五种物品开场可选，出怪时也能部署；悬停和选中反馈明确；成功部署只扣一次能量；塔跨波保留；情侣每波有慌张与放松变化；不同部署顺序不会卡住 Boss 剧情；修改 Excel 后数值确实生效；整局能够胜利、失败并重新开始。
