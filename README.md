# 约会保卫战 · 第一阶段

Phaser + TypeScript + Vite 浏览器 demo。原方案保存于 [docs/方案规划.md](docs/方案规划.md)。

换电脑继续开发：先阅读 [项目进度与交接](docs/项目进度.md)，同步步骤见 [跨电脑同步](docs/跨电脑同步.md)。

原始需求及后续澄清保存在 [聊天上下文](docs/聊天记录/README.md)，供新聊天接续讨论。

## 启动

需要 Node.js 20.19+ 或 22.12+。首次执行 `npm install`，随后执行 `npm run dev`，浏览器打开终端显示的本地地址（默认 http://127.0.0.1:5173）。也可双击 `启动游戏.cmd`。正式构建：`npm run build`；输出为 `dist/`，需通过 HTTP 静态服务器访问，不要直接双击 HTML。

## 试玩

场景 9:16，逻辑画布 540 × 960，与方案的 1080 × 1920 等比对应。

- 鼠标经过街边物品放大 8%；点击选中，显示 8 个部署方格。
- 悬停方格显示范围；点击部署，成功时扣一次能量。
- Esc、再次点击选中物品或点击空白取消；占用位、非法位置、能量不足不扣费。
- 五种物品开场全部解锁，各仅一个实例；部署后不移动、不出售、跨波保留。
- 点击开始本波；清场反馈后手动进入下一波；出怪时也能部署。
- 漏怪到终点扣情侣共同血量；五波存活胜利，血量归零失败，可重开。
- 暂停、1×/2×速度；切换浏览器标签时自动暂停。

第一阶段五种防御物使用同一套基础攻击（按配表的攻击力、间隔、射程、目标数），Boss 使用普通耐久结算。第二阶段再实现吸取、燃烧、捕获、拦截、藤蔓、特殊退场、情侣姿态和巨人终结。当前占位图形为程序绘制。

## Excel 配表

页面“配表与调试”可下载默认模板、导出当前配置、导入 `.xlsx`。导入只暂存，校验通过后点击“应用并重新开始”；失败不改变当前配置或对局。重开保留本次导入，刷新网页恢复默认。不自动存储到本地浏览器。

工作表和列名必须保留；第一行是列名，第二行开始是数据，不能在表前插入标题。支持列重排和空白数据行。不要使用依赖 Excel 重算的公式；导入读取已保存的单元格值。

| 表 | 字段与单位 |
|---|---|
| 全局 | 情侣血量、初始能量、波间反馈秒；仅一行 |
| 狗仔 | ID、名称、血量、移动速度（设计像素/秒）、突破伤害 |
| 防御物 | ID、名称、部署能量、攻击力、攻击间隔秒、射程（设计像素半径）、目标数量 |
| 波次 | 波次、敌人ID、数量、出场延迟秒、生成间隔秒；同波可多行，延迟从本波开始计，行之间可重叠生成 |
| 特殊效果 | 燃烧伤害、燃烧秒、捕获容量、消化秒、阻挡上限；第二阶段预留 |
| Boss | 减伤比例、阶段秒；第二阶段预留；Boss 血量/速度统一在狗仔表，避免双重配置 |
| 资源映射 | ID、素材路径、宽度、高度、锚点X、锚点Y；可留空，使用占位素材 |

固定防御物 ID：`ac`、`car`、`awning`、`parking`、`vine`；敌人 ID：`basic`、`telephoto`、`pro`、`boss`。必须恰好五波，前四波无 Boss，第五波一名 Boss。默认数值是本阶段调试值，并非最终平衡。

资源放 `public/assets/`，配置路径如 `/assets/ac_idle.png`；尺寸按 1080 × 1920 设计单位。可映射五种物品、四种敌人、`couple`、`background`。背景固定填满 9:16。缺失图片回退占位图（背景回退程序街景）。第二阶段会扩展多状态素材映射。

## 开发与验证

- `src/model.ts`：独立战斗状态、路径、部署和五波流程。
- `src/config.ts`：默认数据、Excel 解析/校验和导出。
- `src/scene.ts`：Phaser 场景与鼠标交互。
- `src/main.ts` / `style.css`：DOM HUD、导入入口、结算与适配。
- `npm test`：模拟整局、失败、部署边界、配表往返与错误校验。
- `npm run test:browser`：需先启动开发服务器；使用已安装的 Microsoft Edge 或 Playwright Chromium。截图写入 `test-results/`。

Excel 文件应来自可信的本地编辑流程；当前导入为本地演示用途，未接入网络上传服务。
