# 美术接入记录 · 2026-10-20

## 当前可玩版本

来源：用户桌面「美术资产」。原文件保持不变。运行时资源在 `public/assets/art/`，清单在 `src/art-manifest.json`。

- 74 张静态透明图、14 组动画已导入。`ac_idle.png.png` 在导入时规范成 `ac_idle`，不修改原文件名。
- 透明图最大边 640，动画每帧最大边 384，输出 WebP，保留 alpha。图片和动画共约 8.7 MB，另有约 2.5 MB 净背景。
- 使用统一缩放的精灵图集，没有逐帧裁切。帧数、帧率、循环和事件帧来自各文件夹 JSON，兼容 `fps/loop` 和 `frameRate/repeat` 两种写法；源 JSON 随资源保留。
- 角色足底和物品落点按透明内容边界对齐；同一动画取全部帧的联合边界，避免每帧位置跳动。
- 场景不显示物品名称、消耗等常驻标签。悬停描边，选中后显示部署位和预览，顶部反馈能量扣除。
- **藤蔓是咖啡馆墙上攀附的绿植**。来源为墙面区域，不额外放盆栽；选中后可部署为豆荚。背景其他绿植继续作为装饰。
- 道路、8 个部署位、来源与情侣落点集中在 `src/layout.ts`，对应净背景，不沿用旧折线路径。
- 情侣已接入各波慌张/放松、受击、胜败静态姿态，胜败优先。
- Boss 有独立顶部血条。

## 下一批资源怎么接

1. 继续按当前命名保存完整动画文件夹，含 sheet PNG 与 JSON；逐帧/GIF/预览可以一起保留在源目录。
2. 使用安装 Pillow 的 Python 执行 `python scripts/import-art.py "素材目录"`。脚本只读取源目录，生成运行时纹理和清单。缺少图集或 JSON 参数不一致时会报错。
3. 新动画入库后，还需要根据机制添加状态与触发点。不要仅因文件存在就自动播放剧情。
4. 尺寸或位置不合适，先调整 `layout.ts` 与 `art.ts` 中的显示参数，不重新生成已经可用的原画。

当前透明素材足够继续推进机制。下一步优先做春卷机捕获→消化→吐出及狗仔退场，再做 Boss 阶段与巨人终结。等这些行为正确后再集中调节大小、节奏和特效。
